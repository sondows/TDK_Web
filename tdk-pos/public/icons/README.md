# TDKON app icons

The POS, ADM, KDS, and HOS manifest and Apple home-screen icons are downsampled from the matching source images in `../../../image/`.

- `tdk-{pos,adm,kds,hos}-192.png` and `tdk-{pos,adm,kds,hos}-512.png`: app manifest icons
- `tdk-pos-maskable-512.png`: POS icon with a centered safe area for maskable PWA launchers, derived from the existing POS icon
- `tdk-hos-maskable-512.png`: HOS icon for maskable PWA launchers
- `tdk-{pos,adm,kds,hos}-180.png`: app-specific Apple touch icons
