# TDKON app icons

The POS, ADM, and KDS manifest and Apple home-screen icons are downsampled from the matching source images in `../../../image/`.

- `tdk-{pos,adm,kds}-192.png` and `tdk-{pos,adm,kds}-512.png`: app manifest icons
- `tdk-{pos,adm,kds}-180.png`: app-specific Apple touch icons

The HOS source image is reserved until the HOS application and its installation scope are implemented.
