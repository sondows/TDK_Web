# TDK-POS app icon assets

The PNG files in this directory were generated by high-quality downsampling from `../../../image/파란색 TDK POS 로고 아이콘.png` (1254 × 1254 px). The same TDK-POS design is used by `src/app/favicon.ico`.

- `tdk-pos-192.png` — 192 × 192 px, Android/manifest icon
- `tdk-pos-512.png` — 512 × 512 px, Android/manifest icon
- `apple-touch-icon.png` — 180 × 180 px, iPhone home-screen icon

The manifest and Apple metadata point to these paths. The source image has a centered blue rounded-square mark with white outer corners.
