# KDS 매장망 기기등록 면제 전환

현재 구현과 배포 순서는 [POS / KDS 경로 통일 배포안](UNIFIED-POS-KDS-PATHS.md)을 따릅니다. 새 내부망 주소는 `http://192.168.0.83:3000/tdkkds`, 외부 HTTPS 주소는 `https://tdkon.myasustor.com/tdkkds`입니다.

NAS `eth0`는 `192.168.0.83/24`이며, 매장망은 `192.168.0.0/24`입니다. 기존 `:3000/kitchen`은 새 주소로 이동합니다. 기존 Docker 브리지에서는 앱에 PC IP가 아닌 `172.18.0.1`이 보이는 것이 확인되어, 새 Compose는 호스트 네트워크를 사용합니다. 새 앱 서버는 직접 HTTP 연결의 실제 소켓 IP를 읽어 명시된 매장망인지 확인합니다. 확인된 경우에만 기기등록 검사를 면제하며, 직원 ID·6자리 PIN·KDS 권한·세션 검사는 유지합니다. 소켓 IP가 Docker 브리지나 허용되지 않은 주소로 보이면 외부망으로 취급합니다.

외부 HTTPS는 `tdk-caddy`가 받습니다. 현재 운영 Caddyfile은 모든 일반 요청 헤더를 전달하므로, 배포안의 최소 Caddy 설정으로 네트워크 확인 헤더를 제거해야 합니다. 읽기 전용 확인에서 운영 POS의 표시 헤더 위조가 실제로 네트워크 차단을 우회했습니다. 직원 로그인 우회는 확인되지 않았습니다.

운영 앱·Caddy·DB·백업은 이 코드 작업에서 변경하지 않았습니다. 적용은 별도 승인 후 진행합니다.
