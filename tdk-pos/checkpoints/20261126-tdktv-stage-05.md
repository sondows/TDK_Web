# TDKTV TV-5 — Image Event Messages and Animation

## Implemented

- Added `tv_image_events` Drizzle schema and TEST-only migration with a cascading foreign key to `tv_images`.
- Added ADM-authenticated event list/create/update/delete API. Events can only attach to DP2–DP5 images, text is rendered as plain React text, and an image can hold at most five event rows.
- Added the TDKADM event management page with image selection, an FHD 16:9 preview, draggable event placement, text/background/border settings, animation selector, ON/OFF, and edit/delete.
- Added active events to each matching TV playlist image. The player overlays each event on the same image layer so the old overlay leaves and the next overlay arrives with the corresponding image transition.
- Added repeated 2-second NONE/FADE/PULSE/SLIDE/GLOW event animations and reduced-motion handling. Image transition effects remain independent and fixed at 800 ms.
- Split playlist, image, and playback versions. Editing an event changes the playlist version but does not preload images, change the image index, or restart the current image display timer.
- Preserved TV-4 notice priority. When a notice is active, menu images and their event layers are not rendered.
- Registered the routes in the API inventory. Marked `/api/tdktv/*` as ADM surface in host-access policy; the route still requires ADM session authorization. Existing TDKTV client API reads now use the shared safe JSON reader.
